# gruppo_1_TPSIT
Titolo del Progetto: Sviluppo di un Sistema di Chat di Gruppo con Multi-Server
L'obiettivo del progetto è sviluppare un'applicazione client-server che simuli una chat di
gruppo. Il sistema deve supportare la comunicazione simultanea tra più utenti, gestendo
le connessioni tramite socket e un'architettura multi-server. I gruppi di lavoro dovranno
suddividere le attività per analizzare, progettare, implementare e presentare il progetto
in modo collaborativo.
Fasi del Progetto
1. Analisi iniziale
Ogni gruppo dovrà:
● Definire i requisiti funzionali e non funzionali del sistema;
● Fornire una breve descrizione dell'applicazione (max una pagina), che includa:
○ Obiettivi del sistema (requisiti business).
○ Requisiti funzionali e non funzionali (utente e di sistema).
● Documento con use cases e use case diagram.

2. Progettazione
Progettare la soluzione documentandola con almeno i seguenti diagrammi UML:
sequence diagram, activity diagram, class diagram.
3. Implementazione
Sapendo che:
● Server multi-thread: deve essere capace di gestire più connessioni
contemporaneamente;
● Client: deve permettere agli utenti di:
○ Collegarsi al server;
○ Inviare e ricevere messaggi;
○ Visualizzare notifiche per utenti che entrano o escono dalla chat.

Requisiti minimi:
● Il server deve essere in grado di gestire errori, come connessioni perse o
messaggi non validi.
● Il client deve avere un’interfaccia semplice (anche solo a riga di comando).

Altri requisiti facoltativi:
● Interfaccia grafica;
● Trasferimento di file;
● Chat multipla;
● altro a piacere.

4. Consegna e Presentazione
Alla fine del progetto, ogni gruppo dovrà consegnare:
1. Il codice sorgente del progetto, opportunamente documentato con javadoc.
2. Una relazione che includa:
○ L'analisi iniziale;
○ I diagrammi utilizzati;
○ Una descrizione tecnica dell'implementazione (architettura del codice,
algoritmi principali, eventuali problemi risolti);

3. Una presentazione orale, accompagnati da slide, per illustrare il lavoro svolto e
presentare una demo del sistema in azione.
